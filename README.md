# Cover Maker

Локальная студия для создания обложек журналов в браузере. Приложение работает на вашем компьютере: изображения не отправляются в интернет, а фон удаляется нейросетями U²-Net и MODNet через ONNX Runtime.

## Возможности

- Холст обложки с форматами A4 (300/150 dpi), Letter, квадрат и произвольным размером.
- Слои: изображения и текст, изменение порядка, видимость, дублирование, удаление, прозрачность.
- Изображения: добавление, перетаскивание, масштабирование за углы, поворот, отражение, вписывание в страницу, замена файла.
- Текст: содержимое, шрифт, начертание, размер, интерлиньяж, трекинг, выравнивание, курсив, заглавные, цвет, обводка, плашка за текстом, тень и прозрачность. Двойной клик по тексту на холсте открывает редактирование прямо на макете.
- Удаление фона выбранной модели: U²-Net (универсальная) или MODNet (портретная).
- Комбинированное действие «Вырезать объект»: дублирует слой, оставляет копию с фоном снизу, а слой с вырезанным объектом поднимает выше.
- Отмена и повтор действий, горячие клавиши, экспорт PNG/JPEG с масштабом до 200%.
- Локальные модели скачиваются автоматически при первом использовании и кэшируются в `models/`.

## Быстрый старт

Требуется Python 3.11+ и интернет для первой установки зависимостей и моделей. Windows и Linux поддерживаются; macOS не тестировался, а GPU-ускорение там недоступно.

### Windows

1. Дважды щёлкните `start.bat` или выполните в PowerShell:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\start.ps1
   ```

2. При первом запуске скрипт создаст `.venv`, установит зависимости и откроет `http://127.0.0.1:8765`.

### Linux

1. Установите Python 3.11+, `python3-venv` и сделайте скрипт исполняемым:

   ```bash
   sudo apt install python3 python3-venv
   chmod +x start.sh
   ```

2. Запустите:

   ```bash
   ./start.sh
   ```

   Если `python3` в системе старше 3.11, укажите интерпретатор явно: `PYTHON=python3.12 ./start.sh`. При первом запуске будет создан `.venv`, установлены зависимости и открыт браузер. Если на компьютере нет графической сессии, скрипт сам добавит `--no-browser`; адрес для ручного открытия появится в консоли. Если рядом уже лежит Windows-окружение `.venv`, Linux-скрипт использует отдельный `.venv-linux`.

3. При первом нажатии «Вырезать объект» приложение скачает веса модели: U²-Net около 176 МБ или MODNet около 26 МБ. Дальше они работают без интернета.

Если браузер не открылся автоматически, перейдите по адресу из консоли. Порт по умолчанию — 8765, при занятости выбирается следующий свободный. Параметры: `--port 9000`, `--no-browser`, `--host 127.0.0.1`.

Проект проверен на Windows и в WSL2 Ubuntu (Python 3.12). Сервер, модели и редактор под Linux работают; при отсутствии CUDA 13/cuDNN 9 обработка автоматически идёт на CPU. Для GPU под Linux нужны CUDA 13 и cuDNN 9, совместимые с `onnxruntime-gpu`.

## Как пользоваться

1. Добавьте изображение кнопкой «Изображение» или перетащите файл на холст.
2. Настройте размер и положение: тяните за слой, масштабируйте за углы, вращайте круглым маркером над рамкой.
3. Выберите модель удаления фона в левой панели и нажмите «Вырезать объект», чтобы получить композицию из фона и вырезанного объекта одним действием. Кнопка «Удалить фон слоя» просто заменяет текущее изображение версией без фона.
4. Добавьте текст кнопкой «Текст»; двойной клик по тексту открывает редактирование на холсте, а правая панель содержит все параметры оформления.
5. Экспортируйте результат кнопкой «Экспорт» в PNG или JPEG.

### U²-Net или MODNet

- **U²-Net** — универсальная модель для людей, товаров, автомобилей и животных. Хорошо выделяет крупный объект целиком.
- **MODNet** — портретная модель с матированием краёв: лучше работает с волосами и полупрозрачными деталями на фотографиях людей.

Обе модели работают полностью локально. Выбор модели сохраняется в браузере.

### Горячие клавиши

- `Ctrl+Z` / `Ctrl+Shift+Z` — отмена и повтор.
- `Ctrl+D` — дублировать слой.
- `Delete` / `Backspace` — удалить слой.
- Стрелки — сдвиг слоя, `Shift` + стрелки — шаг в 10 px.
- `Ctrl+E` — экспорт.
- `Esc` — снять выделение или закрыть окно экспорта.
- `Ctrl+Enter` — завершить редактирование текста, `Esc` — отменить его.

## GPU и CPU

Приложение использует `onnxruntime-gpu`, но при отсутствии CUDA/cuDNN автоматически переключается на CPU. На CPU обработка занимает обычно 0,5–2 секунды для изображения до 12 Мп.

- Принудительно CPU: переменная окружения `COVER_MAKER_DEVICE=cpu`.
- Windows: если CUDA/cuDNN установлены отдельно, укажите каталог с DLL: `COVER_MAKER_CUDA_DLL_DIR="C:\path\to\cudnn\bin"`. `start.ps1` также умеет брать библиотеки из установленного PyTorch.
- Linux: `start.sh` ищет `libcudnn.so*` в библиотеках PyTorch, пакетах `nvidia-*` и `/usr/local/cuda*/lib64`, затем выставляет `LD_LIBRARY_PATH` до запуска Python. Можно задать каталог вручную через `COVER_MAKER_CUDA_LIB_DIR=/path/to/lib`.
- Если CUDA-библиотеки несовместимы с `onnxruntime-gpu`, приложение не падает: первый запуск провайдера завершается ошибкой, затем модель загружается на CPU.
- Устройство, на котором реально выполнилась обработка, показывается в уведомлении и в бейдже «локально · GPU/CPU».

## Модели и источники

- U²-Net: [репозиторий rembg](https://github.com/danielgatis/rembg), веса [u2net.onnx](https://huggingface.co/tomjackson2023/rembg/resolve/main/u2net.onnx).
- MODNet: [официальный репозиторий](https://github.com/ZHKKKe/MODNet), ONNX-веса [Xenova/modnet](https://huggingface.co/Xenova/modnet).

Файлы моделей лежат в `models/` и исключены из git. Загрузка идёт с Hugging Face; для работы после первого скачивания интернет не нужен.

## API

Сервер отдаёт статический интерфейс и API на `127.0.0.1`:

- `GET /api/health` — состояние сервера и доступные провайдеры ONNX Runtime.
- `GET /api/models` — наличие и состояние моделей.
- `POST /api/models/{id}/download` — запустить фоновую загрузку модели.
- `POST /api/remove-background` — `multipart/form-data` с полями `file`, `model` (`u2net` или `modnet`), `feather` (0–20). Возвращает PNG с альфа-каналом и заголовки `X-Cover-Device`, `X-Cover-Duration-Ms`.
- `GET /api/docs` — интерактивная документация FastAPI.

Ограничения: файл до 40 МБ, изображение до 60 мегапикселей.

## Структура

```
app/            FastAPI, загрузка моделей, пред/постобработка
web/            интерфейс: canvas-редактор, слои, инспектор, экспорт
models/         файлы .onnx (скачиваются автоматически)
tests/          unit- и inference-тесты
start.ps1       запуск для Windows
start.sh        запуск для Linux
```

Проверка на Windows:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

На Linux:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Если использовался отдельный Linux-venv, замените `.venv` на `.venv-linux` (или путь из `COVER_MAKER_VENV`).

## Ограничения

- Проект не сохраняется между сессиями: результат выгружается в PNG/JPEG. Автосохранение и файлы проекта — следующий логичный шаг.
- Список шрифтов берётся из системы; свои TTF пока не подключаются.
- Качество маски зависит от снимка; для портретов обычно лучше MODNet, для предметов — U²-Net.
- Приложение рассчитано на локальный однопользовательский запуск и не имеет авторизации; не открывайте его в интернет.
